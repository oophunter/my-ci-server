# Lotto 6/45 AI Simulator & Recommender

로또 6/45 번호를 시뮬레이션 기반으로 자동 생성하여 통계적으로 추천해주는 웹 애플리케이션입니다.

## 핵심 기능

1. **AI 시뮬레이션 기반 추천**:
   - 1회 추천 시, 백그라운드에서 100회의 가상 로또 추첨을 수행합니다.
   - 각 추첨마다 1~45 사이의 고유한 난수 6개를 추출합니다.
   - 총 100회(600개 번호)의 등장 빈도수를 실시간 집계하여 가장 많이 나온 상위 6개 숫자를 1세트로 추천합니다.
   - 빈도수가 동률일 경우, 특정 번호에 편향이 없도록 무작위 추출(Tie-breaking)을 적용합니다.
   - 이 전체 시뮬레이션 과정을 독립적으로 5회 반복하여 총 5개의 추천 번호 세트를 제공합니다.

2. **인터랙티브 분석 대시보드**:
   - 45개의 로또 번호 판을 시각적인 열지도(Heatmap) 그리드로 구성하여 실시간 빈도수 밀도를 직관적으로 보여줍니다.
   - 각 추천 세트별 개별 빈도수(100회 기준) 및 5개 세트 전체의 종합 빈도수(500회 기준) 통계를 선택하여 분석할 수 있습니다.
   - 각 번호에 마우스를 올리면 정확한 출현 빈도 횟수를 툴팁으로 확인할 수 있습니다.

3. **고급 UI/UX**:
   - 눈이 편안한 다크 모드 및 세련된 글래스모피즘(Glassmorphism) 테마.
   - 실제 한국 로또 공 색상 규격을 적용한 입체감 있는 3D 로또볼 디자인 (1~10 황색, 11~20 청색, 21~30 적색, 31~40 회색, 41~45 녹색).
   - 추천 번호 생성 시 차례대로 공이 나타나는 자연스러운 지연(Staggered) 애니메이션 효과.

## CI/CD 파이프라인

이 프로젝트는 현대적인 DevOps 개념을 바탕으로 지속적 통합(CI/CD)을 적용하여 관리됩니다.

- **CI 도구**: GitHub Actions (`.github/workflows/ci.yml`)
- **작동 트리거**: `main` 브랜치로의 `push` 또는 `pull_request` 발생 시 자동 실행
- **검증 단계**:
  1. **코드 체크아웃 및 캐시 설정**: 소스 코드를 가져오고 의존성을 캐싱하여 빌드 속도 개선.
  2. **의존성 설치**: `npm ci`를 통해 프로젝트 빌드 및 테스트에 필요한 패키지들을 일관되게 설치.
  3. **단위 테스트 실행**: Jest를 이용해 번호 생성 정렬 상태, 중복 여부, 범위 검증 및 빈도수 정렬 정밀성 검증 (`npm run test`).
  4. **프로덕션 빌드 검증**: Vite 컴파일러를 실행하여 배포 가능한 상태로 번들링이 문제없이 완료되는지 검증 (`npm run build`).

## 로컬 개발 및 실행 방법

### 의존성 설치
```bash
npm install
```

### 로컬 개발 서버 실행
```bash
npm run dev
```

### 단위 테스트 실행
```bash
npm run test
```

### 프로덕션 빌드 생성
```bash
npm run build
```
